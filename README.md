# Global Health Outcomes and Healthcare Expenditure Analysis (1960–2025)

## Project Overview
This Power BI capstone project analyzes global health outcomes across 264 countries using the World Development Indicators dataset published by the World Bank.

## Project Objectives
- Analyze trends in life expectancy.
- Examine healthcare expenditure patterns.
- Evaluate road traffic mortality trends.
- Generate data-driven insights and recommendations.

## Tools Used
- Power BI Desktop
- Power Query
- DAX
- World Development Indicators Dataset (World Bank)

## Dashboard Features
- KPI Cards
- Trend Analysis
- Country Comparisons
- Interactive Slicers
- Insights and Recommendations

## Selected Indicators
- Total Life Expectancy
- Female Life Expectancy
- Health Expenditure (% of GDP)
- Mortality caused by Road Traffic Injury

## Key Findings
- Global life expectancy has improved over time.
- Healthcare expenditure has generally increased over the years.
- Female life expectancy exceeds the global average life expectancy.
- Average road traffic mortality has generally declined.
